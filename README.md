# Library Management System (Java)

A console-based Library Management System built in Java to practice OOP, Collections and File Handling.

## Features
- [X] Book class
- [ ] Add a book
- [ ] Displays all books
- [ ] Search a book by title
- [ ] Delete a book
- [ ] Add a member
- [ ] Issued a book
- [ ] Return a book
- [ ] Save and load data using files

## Tech Used
- Java
- OOP (classes and objects)
- Collections (ArrayList)
- File Handling

## Project Structure
- Book.java: stores book details
- Member.java: stores member details
- Library.java: library operations
- Main.java: program entry point

## How to Run
1. Clone this repository
2. Open it in VS Code
3. Run Main.java

## Status
In progress. Features are added step by step.
